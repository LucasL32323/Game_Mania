🎮 Game Mania 

Bem-vindo ao repositório do Game_Mania

Este é um projeto  de um site simples de e-commerce  focado no público gamer. Aqui, simulamos a venda de jogos, periféricos (como mouses, teclados, fones) e outros artigos do mundo dos games.

O objetivo principal deste projeto é colocar em prática conceitos importantes do desenvolvimento web, desde a interface que o usuário vê até os bastidores de segurança e banco de dados.

🛠️ Funcionalidades do Projeto

Este site não é apenas uma vitrine visual, ele possui funções reais e interativas:

Cadastro de Usuários: Qualquer pessoa pode criar uma conta no site fornecendo seus dados.

Sistema de Login: Acesso restrito para usuários cadastrados entrarem em suas contas.

Segurança e Criptografia: As senhas dos usuários não são salvas de qualquer jeito. Elas são "embaralhadas" (criptografadas) antes de irem para o banco de dados, garantindo que ninguém consiga lê-las.

Fluxo de Compras: Sistema que simula a escolha de produtos, adição ao carrinho e finalização da compra.

Armazenamento de Dados: Uso de um banco de dados para guardar de forma segura os cadastros, produtos e histórico.

💻 Tecnologias Utilizadas

(Observação: Você pode editar esta lista de acordo com as ferramentas exatas que usou no seu código)

Front-end: HTML, CSS, JavaScript e Bootstrap (layout responsivo e estilização).

Back-end: Node.js, Python, PHP, etc.

Banco de Dados: Ex: MySQL, PostgreSQL, MongoDB, etc.

🚀 Como testar o projeto no seu computador

Se você quiser baixar e rodar este site na sua própria máquina, siga este passo a passo simples:

Clone o repositório:
Faça o download do projeto ou use o comando abaixo no seu terminal:

git clone https://github.com/LucasL32323/Game_Mania_Versao_Alpha.git


Abra a pasta do projeto:
Entre na pasta que acabou de ser baixada usando o seu editor de código (como o VS Code).

Configure o Banco de Dados:

Crie um banco de dados local na sua máquina.

Procure o arquivo de configuração no projeto e coloque as informações do seu banco (usuário e senha).

Instale as dependências (se houver):
Caso o projeto use algum gerenciador de pacotes, rode o comando de instalação (ex: npm install).

Inicie o servidor:
Rode o comando para iniciar o site e abra o link fornecido no seu navegador (geralmente http://localhost:3000).
